# 参考案例：阿联酋（UAE）× 交通规划

> 本目录是**随技能分发的示范案例**，用来演示「穷尽检索 → 逐条核验 → 判定 → 出页」全流程。
> 生成日期：2026-10-02 ｜ 汇率：1 AED ≈ 1.826 CNY（当日多来源一致）
> **不构成申请建议**：标「待核验」的字段未取得官方页，使用前必须回官网复核。

## 为什么是这个组合

按「随机抽国家 + 专业」抽中 **阿联酋 × 交通规划**。它是一个有代表性的压力测试：

- 阿联酋高校**基本全英语授课**，省去语种筛选；
- 但**没有独立的交通规划硕士** —— 交通内容一律挂在土木/基建硕士下（这就是"穷尽检索+排除留痕"要解决的问题）；
- 7 个酋长国在生活成本、签证办理渠道上不同，但招生标准由联邦教育部（CAA）统一认证 —— 属「联邦制 + 多层级」典型案例。

### 两个最该记住的结论

1. **阿联酋不在「15–20 万总预算」的可行范围内**：学费本身就要 ¥14.5 万–33 万，再加 2 年生活费（AED 33,600–54,000/年），总花费 ¥26 万–48 万。唯一贴近预算的是 UAEU 土木（差 ¥6.7 万，靠兼职可补 → ②加兼职可行）。
2. **"交通规划"在阿联酋没有独立学位**：想读交通必须走土木硕士 + 选交通方向/论文题目。若目标是交通规划本体，荷兰（TU Delft）、英国（Leeds、UCL）等设独立交通规划硕士的国家更对口 —— 这个负向结论已按「排除也要留痕」写进 `exclusions.json`。

## 复现步骤（三条命令）

```bash
# 1) 审计数据（字段完整性 / 链接覆盖 / 核验日期 / 政策年份）
node ../scripts/audit_dataset.js data.json

# 2) 校验判定口径（录取四类 + 预算四档，含缺口与兼职上限）
node ../scripts/verify_rules.js data.json

# 3) 构建页面 + 烤静态快照（result.html 是中间产物，交付静态快照后可删）
node ../scripts/build.js result.html data.json
node ../scripts/snapshot_static.js result.html result-static.html
```

## 数据纪律（本案例如何遵守「零记忆交付」）

- **只用语种/学位/学费/语言/时限等可核验字段**作结论；每个数字都能指到 source；
- 5 条记录的关键字段来自**本轮实时核验的官方页面**（UAEU 官方费率表、AUS 官方学费页与知识库、KU 官方 FAQ、沙迦大学官方项目页、阿联酋政府官方门户 u.ae）；
- 2 条标 `verified:false`（沙迦大学学分单价、赫瑞-瓦特迪拜全部字段）—— **官方页没拿到就不冒充核验过**；
- 生活费、兼职收入属**估算**，在记录里写明估算口径与依据（官方宿舍价 / 当地合租行情），不写成官方数字；
- `verifiedFields` 记录"本轮到底核了什么"，`fetchedAt` 记录抓取日期，便于日后判断过期。

## 换国家/换专业怎么做

本案例的可复用部分不是数据，而是**流程**：

1. 按 `references/finding-schools.md` 的官方名录穷举该「地区 × 专业」（阿联酋对应 CAA 认证院校名录 + 各校官网 graduate programs 页）；
2. 逐条按 20 项字段核验，拿不准的标「待核验」；
3. 把不符合的（语言不符、方向不符、无该学位）写进 `exclusions.json`，含理由与来源；
4. 用 `scripts/build.js` 出页 —— 上面三条命令完全一致，不需要改模板。
