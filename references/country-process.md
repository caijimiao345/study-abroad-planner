# 各国申请流程库（国家级流程 + 学校级流程）

> ⚠️ **本文件是检索线索与核对清单，不是数据结论。**
> 其中的流程、数字、机构名、字段口径都必须由 agent **实时联网核验官网**后才可引用；
> 模型记忆只能决定"去哪里查、查什么"，不得直接充当数据。详见 SKILL.md「铁律零：零记忆交付」。

用途：留学申请**不只是"投个网申"**。每个国家都有各自的**前置认证/审核**、**统一递交平台**、**签证关键文件**与**落地登记**。漏掉任一环节都会卡在最后一步。

用法：
1. 先读本国的「前置 → 递交 → 签证 → 落地 → 毕业路径」五段
2. **前置认证**是最容易漏、最耗时的环节（德国 APS 2–3 个月、法国 Campus France、意大利价值声明、西班牙 homologación…）
3. 「监控清单」交给定时任务（`references/automations.md`）
4. 学校级流程见文末通用模板（每条数据里也有 `schoolProcess`）

## 欧洲

### 德国 🇩🇪
- **前置**：**APS 审核（硬前置，2–3 个月，材料造假永久拒审）** → 详见 `germany-process.md`
- **递交**：uni-assist（多数高校）或学校自有系统（TUMonline）；冬季学期多 1–5 月截止
- **录取逻辑**：按**课程模块匹配（Modulkatalog）**，不是均分排名 → 课程描述要写细
- **签证**：D 签；关键文件 = 录取通知 + APS + **Sperrkonto 限制账户**（年标准逐年调整）+ 公立保险
- **落地**：外管局（Ausländerbehörde）预约延签（大城市排队数月）
- **毕业路径**：18 个月找工签 → EU 蓝卡 → 蓝卡 21–27 个月永居 → 入籍 5 年（德语 B1）
- **监控**：APS 周期/费用公告、TestDaF/DSH 考位、uni-assist 窗口、限制账户金额

### 法国 🇫🇷
- **前置**：**Campus France「Études en France」程序（必经）**；法语项目需 DELF B2/TCF
- **递交**：通过 Études en France 平台申报志愿（1–3 月为主），学校评审后进行**面试（entretien）**
- **签证**：VLS-TS（长期学生签，无需另办居留卡但需入境后向 OFII 确认）
- **落地**：OFII 在线确认 + 银行开户 + 社保（CVEC 缴纳）
- **毕业路径**：APS 临时居留（找工/创业 12 个月）→ 工作居留 → 5 年可申永居
- **监控**：Campus France 开放/截止、语言考试（TCF/DELF）考位、奖学金（Eiffel）截止

### 荷兰 🇳🇱
- **前置**：无全国性学历审核，但**必须通过 Studielink 注册**（全国统一申请入口，部分私校除外）
- **递交**：Studielink 选项目 → 学校系统补材料 → 部分项目有入学测试/面试
- **签证**：**学校代办 IND 居留许可（MVV + VVR）**，学生需先付学费或提供资金证明
- **落地**：市政厅 BSN 登记、领居留卡
- **毕业路径**：**Orientation Year（zoekjaar）1 年**找工 → 高技术移民（HSM）→ 5 年可申永居
- **监控**：Studielink 窗口、学校资金证明要求、IND 月标准

### 比利时 🇧🇪
- **前置**：**学历认证**（荷语区 NARIC-Vlaanderen / 法语区社区教育部门）；部分专业需作品集或入学考试
- **递交**：各校自有系统（荷/法语区流程不同，联合学位要跨社区）
- **签证**：D 签；关键 = 录取信 + 资金证明（月标准 ×12）或 **Annex 32 担保**
- **落地**：入境 8 日内市政厅登记 → 领 A 卡
- **毕业路径**：Search Year 12 个月 → Single Permit → 5 年永居
- **监控**：各社区认证流程、Master Mind 奖学金（法兰德斯政府）

### 意大利 🇮🇹
- **前置**：**Universitaly 预注册**（必经）+ **价值声明（Dichiarazione di valore / CIMEA 认证）**
- **递交**：预注册 + 学校申请（部分需入学考试，艺术类需作品集）
- **签证**：D 签；资金证明 + 住宿证明 + 保险
- **落地**：**入境 8 日内办居留许可**（邮局 kit）+ 税号
- **毕业路径**：待业/找工许可 12 个月 → 工作居留 → 5 年 EU 长期居留
- **监控**：Universitaly 开放窗口、价值声明周期、DSU 大区助学金申请期

### 西班牙 🇪🇸
- **前置**：**学历对等认证（homologación / equivalencia）**——周期长，务必提前
- **递交**：各校自有系统（大区差异大）
- **签证**：D 签；资金证明（100% IPREM）+ 无犯罪双认证 + 体检
- **落地**：**TIE 居留卡**（入境 1 个月内）+ 住家证明（empadronamiento）
- **毕业路径**：找工签 12 个月；**读书年限可计入 5 年永居年限**
- **监控**：学历认证进度、各校（大区）申请窗口与学费档

### 葡萄牙 🇵🇹
- **前置**：学历认可（DGES 自动认可或学校认可）
- **递交**：学校系统
- **签证**：D 签（学习）；资金 + 住宿 + 保险
- **落地**：AIMA 登记 + NIF 税号
- **毕业路径**：找工居留 → 5 年可申永居

### 瑞士 🇨🇭
- **前置**：学校申请（ETH/EPFL 有自有系统）；**州政府审批居留**（决定权在州）
- **签证**：D 签；资金证明（月标准高）+ 州审批文件
- **落地**：市镇登记（Einwohnerkontrolle）+ B 居留卡
- **毕业路径**：**6 个月找工期**，但工作许可有配额、雇主优先本国人——非 EU 就业转化最难档之一
- **监控**：州审批时长、配额政策、SEM 公告

### 奥地利 🇦🇹
- **前置**：学校录取 + 部分项目入学考试
- **递交**：学校系统
- **签证**：D 签 + **居留许可（Aufenthaltstitel）**——可在境内递交，审批较慢
- **落地**：Meldezettel 登记 + 保险
- **毕业路径**：12 个月找工 → 红白红卡
- **监控**：居留许可审批时长、德语考试（德语授课）、OeAD 奖学金

### 英国 🇬🇧
- **前置**：无全国学历审核（学校自行评估中国院校 List）
- **递交**：学校系统/UCAS（仅本科）；硕士直接申请，**分轮次 rolling**
- **签证**：CAS → Student visa；资金证明**连续存满 28 天**；肺结核检测
- **落地**：eVisa/BRP + 警局登记（部分）+ GP 注册
- **毕业路径**：Graduate Route 2 年（2027 起拟收紧）→ Skilled Worker 5 年永居
- **监控**：院校分轮截止、CAS 发放时长、Graduate Route 政策变化

### 爱尔兰 🇮🇪
- **前置**：无；学校按 List 评估
- **递交**：学校系统（多数 rolling）
- **签证**：Stamp 2；资金 = 第一年学费 + €12,000 生活费（6 个月流水）
- **落地**：IRP 卡注册 + PPS 号（打工用）
- **毕业路径**：Third Level Graduate Scheme **2 年** → Critical Skills Permit 2 年 → Stamp 4
- **监控**：院校截止、IRP 预约、Critical Skills 职业清单

### 北欧（瑞典/丹麦/芬兰/挪威/冰岛）
- **前置**：多国走**全国统一申请平台**（瑞典 universityadmissions.se、芬兰 Studyinfo.fi、丹麦 optagelse.dk）
- **递交**：统一平台 + 学校补件；部分项目需入学测试
- **签证**：居留许可（瑞典 Migrationsverket / 芬兰 Enter Finland / 丹麦 ST1 / 挪威 UDI）；需学费支付或资金证明
- **落地**：人口号/CPR/Personnummer 登记（决定银行、医疗、打工）
- **毕业路径**：找工居留（各国不同，丹麦/瑞典较友好）→ 永居普遍需**本地语言**
- **监控**：统一平台截止（多为 1 月中）、资金标准、居留许可审批时长

### 中东欧（波兰/捷克/匈牙利/爱沙尼亚等）
- **前置**：学历认证/承认（各国不同）；**匈牙利 Stipendium Hungaricum 全奖**需单独申请
- **递交**：学校系统（爱沙尼亚多用 DreamApply）
- **签证**：D 签；资金标准低（欧盟最低档）+ 回程旅费（波兰）
- **落地**：居留卡 + 保险
- **毕业路径**：欧盟学历互认；5 年 EU 长期居留；入籍多需本地语 B1
- **监控**：各校窗口、奖学金截止（1–3 月）、居留卡办理时长

## 亚洲

### 中国香港 🇭🇰
- **前置**：无；学校评 List
- **递交**：各校网申（**早申优势明显**，留位费高）
- **签证**：**学生签证（入境许可，学校向入境处担保代办）** → 逗留 D 签注
- **落地**：身份证 + 银行开户（可选）
- **毕业路径**：IANG **2 年**（无条件）→ 续签需就业；连续通常居住 7 年可申永居
- **监控**：各校轮次与留位费截止、入境处审批时长

### 中国澳门 / 中国台湾
- **中国澳门**：学校网申 → 学生逗留许可（高等教育辅助部门/治安警察局）→ 落地登记
- **中国台湾**：学校网申 → **入台证（需通过指定流程办理）** → 入境后办居留证
- **监控**：各校申请期（多为 1–4 月）、入台证/逗留许可办理时长

### 新加坡 🇸🇬
- **前置**：无；学校按院校层级与成绩评估
- **递交**：学校网申（分轮次）
- **签证**：录取 → **SOLAR 系统登记 → IPA → 入境换 Student's Pass**（体检 + 缴费）
- **落地**：ICA 换卡 + 银行开户
- **毕业路径**：EP/ONE Pass（雇主办，薪资门槛+COMPASS 打分）；无统一找工宽限，需提前锁定 offer
- **监控**：EP 薪资门槛与 COMPASS 规则调整、各校轮次

### 日本 🇯🇵
- **前置**：**导师内诺（研究型尤其必须）**；日语项目需 JLPT N2+（英授项目免日语）
- **递交**：学校出愿（多为 6–8 月 / 11–1 月）→ 部分有笔试面试
- **签证**：录取 → 学校代办**在留资格认定证明书（COE）** → 凭 COE 办留学签证
- **落地**：在留卡领取 + 市役所登记 + 国民健康保险
- **毕业路径**：特定活动（就职活动）签证 → 技术·人文知识·国际业务签证 → 居住 10 年（高度人才积分可缩至 1–3 年）
- **监控**：导师套磁窗口、出愿期、JLPT 考位（7/12 月）、MEXT 奖学金截止

### 韩国 🇰🇷
- **前置**：部分项目需 TOPIK；学历需海牙认证/领事认证
- **递交**：学校系统（多为 3–5 月 / 9–11 月两轮）
- **签证**：D-2 学生签；存款证明（约 US$10,000 等值）
- **落地**：外国人登陆证（90 天内）+ 银行开户
- **毕业路径**：D-10 找工签 → E-7 工作签 → F-2/F-5（计分制）
- **监控**：各校两轮窗口、TOPIK 考位、GKS 奖学金截止

### 马来西亚 🇲🇾
- **前置**：学历认证（部分需 MQA 认可）
- **递交**：学校系统
- **签证**：**EMGS 一站式**：录取 → eVAL（签证批准信）→ 入境贴 Student Pass；体检在 EMGS 指定机构
- **落地**：护照交学校贴签 + 报到
- **毕业路径**：Employment Pass（雇主办）；PR 门槛极高，多数人回国或去新加坡
- **监控**：EMGS 处理时长与政策、eVAL 有效期

### 泰国 / 越南 / 菲律宾 / 印尼
- **递交**：学校系统（部分需面试）
- **签证**：Non-ED（泰国）/ 学生签，需学校出具录取与担保文件
- **落地**：续签/居留登记（各国差异大）
- **监控**：签证续签规则、学校窗口

## 大洋洲与美洲

### 澳洲 🇦🇺
- **前置**：无学历审核，但**真实学生要求（GS/GTE）**严格：需写清学习动机与资金
- **递交**：学校系统 → 录取 → 缴首期学费 → **CoE**
- **签证**：subclass 500；**OSHC 保险（必买）** + 资金证明（年生活费标准）+ 体检
- **落地**：TFN 税号 + 银行开户 + USI
- **毕业路径**：485 毕业生签（硕士 2 年）→ 技术移民 189/190/491（EOI 打分 + 州担保）/ 雇主担保 186
- **监控**：年生活费标准、485 年龄与时长政策、各州州担保清单

### 新西兰 🇳🇿
- **前置**：学校评估；部分专业需作品集/工作经验
- **递交**：学校系统
- **签证**：学生签；资金证明（约 NZ$20,000/年）+ 体检
- **落地**：IRD 税号 + 银行
- **毕业路径**：Post-study Work Visa（学制长度决定时长）→ **绿名单职业（测量/工程/医护）移民路径最清晰**
- **监控**：绿名单更新、资金标准、工签政策

### 加拿大 🇨🇦
- **前置**：学校录取 → **PAL/TAL（省证明信，2024 起要求，有名额限制）**
- **递交**：学校系统（分轮）；**PGWP 资格与专业领域挂钩（2024 起收紧）**
- **签证**：Study Permit；**GIC（C$20,635 生活成本）+ 第一年学费**；生物信息采集
- **落地**：SIN 号 + 银行 + 医疗（各省不同）
- **毕业路径**：**PGWP（1–3 年）→ Express Entry（CEC）**；省提名（PNP）各省独立
- **监控**：PAL 名额政策、PGWP 专业清单、各省 PNP 邀请分数

### 美国 🇺🇸
- **前置**：学校申请（GRE/GMAT 视项目）+ 部分项目面试
- **递交**：学校系统；部分项目需 WES 学历认证
- **签证**：录取 → **I-20** → 缴 **SEVIS 费** → 填 DS-160 → **面签（F-1）**；需证明可支付第一年全额
- **落地**：SSN（有校内工作才可办）+ 银行 + 保险
- **毕业路径**：OPT 12 个月（STEM 可延长 24 个月）→ **H-1B 抽签** → 绿卡（EB2/EB3 对中国大陆出生者排期极长）
- **监控**：面签预约等待时间、SEVIS/签证费、OPT/H-1B 政策、STEM 专业清单（CIP code）

### 阿联酋 / 土耳其 / 南非
- **阿联酋**：学校申请 → 学生签（学校担保）→ 居留签；**无常规永居/入籍路径**
- **土耳其**：学校申请（部分需 YÖS 考试）→ 学生签 → 居留许可
- **南非**：学校申请（学历评估 SAQA）→ 学生签（资金证明 + 保险）→ 找工
- **监控**：各国签证政策与学校窗口

## 学校级申请流程（通用模板，每条数据里也带 schoolProcess）

```
① 官网项目页确认要求与截止（每年 8–11 月更新下一申请季口径）
② 注册申请账号（学校系统 / uni-assist / Studielink / Campus France / DreamApply …）
③ 备齐材料：成绩单+学位证明（部分需公证/认证）+ 语言成绩 + 推荐信 + PS + CV
   （设计类加作品集；研究型加研究计划书；德国加课程描述；美国部分加 WES）
④ 递交申请：上传材料 + 邀请推荐人在线提交 + 缴申请费
⑤ 面试/笔试/入学测试（如有）→ 等待结果（4–12 周，rolling 项目更快）
⑥ 接受 offer + 缴押金/留位费（港校/商科押金高，注意退还条件）
⑦ 换取签证前置文件（CAS / COE / IPA / 在留资格 / eVAL / PAL）+ 申请宿舍
⑧ 递签 → 落地注册（居留卡 / 学生证 / 银行 / 税号）+ 参加 orientation
```

**三条经验**：
1. **前置认证先启动**（APS/价值声明/homologación/PAL），它们是最长的一条关键路径；
2. **材料描述要写细**（课程描述、学分匹配表）——德荷等国按内容匹配录取，不是看均分排名；
3. **押金与名额要早**（港校留位费、加拿大 PAL 名额、澳洲 CoE 名额都有限）。
