德国是最典型的「流程决定成败」国家：**APS 不过，一切白搭**。本文件是德国方向的独立作业手册，配合 `finding-schools.md` 使用。

## 一、时间轴总览（以 2028 年 10 月入学为例）

```
2026 年 Q4 ── 语言启动（德语 DSH/TestDaF 或 英语 IELTS/TOEFL）+ 选校调研
2027 年 Q1 ── ★ APS 材料准备并递交（周期 2–3 个月，务必最先启动）
2027 年 Q2 ── APS 面谈/审核（部分人免面谈）+ 语言考试首考
2027 年 Q3 ── 补考语言（如需要）→ 课程描述/学分匹配表准备
2027 年 11 月 ─ 2028 年 3 月 ── 申请窗口（多校 1–5 月截止，TUM 等冬季学期 1–5 月）
2028 年 4–7 月 ── 录取 → 缴纳学期费 → 申请宿舍
2028 年 6–8 月 ── ★ 开限制账户（Sperrkonto）+ 买保险 + 递签（6–12 周）
2028 年 8–9 月 ── 落地 → 外管局延签 → 注册入学
```

⚠️ **顺序要点**：APS（2–3 个月）→ 语言 → 申请 → 签证（含限制账户）。APS 是唯一的硬前置，**它是唯一"花钱也可能重来"的环节**，材料造假会被永久拒审。

## 二、APS 审核（Akademische Prüfstelle）详解

**性质**：德国驻华使馆文化处留德人员审核部，核实中国学历真实性——**中国（含港澳台地区按各自规定）学生申请德国高校的强制前置**。

| 项目 | 内容（以当年官方为准） |
|---|---|
| 适用人群 | 在中国大陆取得学历、申请德国高校者；**纯德国高中毕业 / 部分国际课程、已在德国高校就读者可免**——以 APS 官网判定为准 |
| 审核类型 | ①**一般国内申请人程序**（在读/毕业本科）②团体审核（合作项目）③材料审核（部分硕士项目/已在德者）④德适考试 TestAS（本科） |
| 材料清单 | 小学/初中/高中毕业证、高考成绩、大学录取花名册、成绩单、学位证/在读证明（**全部需公证**）、APS 申请表、护照复印件、照片、缴费凭证 |
| 费用 | 一般国内申请人约 ¥2,500（含首次面谈；具体以官网当年公示为准） |
| 周期 | **2–3 个月**（旺季更久）；面谈排期可能额外等待 |
| 面谈 | 一般程序含 20 分钟左右**面谈**（可用英语或德语），围绕成绩单上课程提问，考察学历真实性；部分类型免面谈 |
| 结果 | 通过后发 **APS 证书**（10 份免费副本可用）；未通过可复审（次数有限、费用另计） |
| 有效期 | APS 证书**长期有效**（但部分高校要求近年内签发，按学校规定） |
| 官网 | https://www.aps.org.cn （唯一官方渠道） |

**常见坑**：
1. **材料造假 = 永久拒审**，没有补救；
2. 公证需要时间（各地公证处 1–2 周），务必提前；
3. 面谈是"验真"不是"考专业"，但**成绩单上零学分的选修课也可能被问到**；
4. APS 只是"学历真实性"，**不等于录取**——录取还要走学校流程（见第四节）；
5. 学校改名/合并（如独立学院转设）要额外提供学校沿革证明。

## 三、语言要求（三件事要分清）

| 节点 | 德语授课 | 英语授课 |
|---|---|---|
| **入学语言** | DSH-2 / TestDaF 4×4（部分接受 telc C1 Hochschule、歌德 C2）；**部分项目允许"条件录取 + 语言班"** | IELTS 6.5 / TOEFL 90 档（各校不同） |
| **毕业语言** | 以德语修课与考核（本身即德语） | **通常无德语毕业要求**；但企业实习/论文可能需德语 |
| **永居/入籍语言** | **入籍需德语 B1**（另有入籍考试）；永居视通道 A1–B1 | 同左——**英语授课也要考德语** |

**语言考试与考位**（需监控）：TestDaF 每年多次（中国大陆考点集中在少数城市，**考位紧张**）；DSH 由各德国高校自办（多需到德国考）；歌德学院考试常年开放。

## 四、申请递交渠道（三条路，别走错）

| 渠道 | 适用 | 要点 |
|---|---|---|
| **uni-assist** | 多数德国高校（尤其非 TUM/LMU 等自建系统者） | 统一平台，按项目逐个提交；需寄送材料；提前 4–6 周 |
| **学校自有系统** | TUM（TUMonline）、部分精英大学 | 按项目要求单独注册提交；课程描述/学分匹配表很关键 |
| **直接联系院系** | 部分博士/研究型硕士 | 导师内诺制（同日本） |

**学分匹配（Modulkatalog）**：德国硕士录取不是"均分排名"，而是**把你的课程逐门对到他们的本科模块**。因此**课程描述（Course Description）写得越细越好**（课时、内容、教材、考核方式），这是中国学生的常见失分点。

## 五、签证与资金（第二年也要准备）

- 签证类型：**德国留学签证（D 签）**，凭录取 + APS + 限制账户 + 保险递交
- **资金证明**：Sperrkonto 限制账户（年标准逐年上调，2025 口径 €11,904，按当年官方复核），一次性存入，到账后按月解冻
- 保险：公立保险（TK/AOK 等）约 €120/月，注册入学必需
- 落地后：**外管局（Ausländerbehörde）延签**，需预约（大城市排队数月，落地即办）
- 兼职：**全年 140 个全天 / 280 个半天**（约 20h/周）；HiWi（科研助理）岗位免税且时薪更高，是德国留学的"最优打工路径"

## 六、毕业后的路径（德国很划算，但要规划）

```
毕业 → 18 个月找工签（Job-seeking visa）
     → EU 蓝卡（薪资门槛，短缺职业/年轻毕业生有折扣档）
        → 蓝卡 21 个月（B1 德语）或 27 个月（A1）可申永居
           → 入籍：通常 5 年（新法，含入籍考试 + B1 + 放弃中国籍）
```

**关键**：德语决定天花板。德语授课项目天然解决；**英语授课项目若想留德，必须自费补德语**（否则就业面被限制在少数国际团队）。

## 七、监控清单（交给定时任务）

| 监控项 | 频率 | 说明 |
|---|---|---|
| APS 预约/审核周期变化 | 每月 | aps.org.cn 公告（周期、费用、面谈排期、免审政策调整） |
| TestDaF / DSH 考位与考试日期 | 每月 | 考位紧张，需提前抢；DSH 需关注目标高校的校外考试安排 |
| 雅思/托福考位（英语项目） | 每月 | 出分与送分时间要留够 |
| 目标校申请窗口（uni-assist / TUMonline） | 每周 | 冬季学期（10 月入学）通常 1–5 月；夏季学期（4 月入学）通常 10–1 月 |
| 限制账户金额标准 | 每半年 | 官方数字逐年上调 |
| 蓝卡薪资门槛 / 入籍语言要求 | 每半年 | 政策调整频繁 |
