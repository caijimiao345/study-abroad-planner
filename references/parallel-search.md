# 并行检索计划模板（把"穷尽检索"拆成可并行的分片）

用途：当用户指定多个地区 × 多个专业方向时，**穷尽检索是大工作量**。本文件把它拆成互相独立的分片，交给多个子 Agent 并行执行，最后在主 Agent 处合并。单 Agent 执行时按同样的分片顺序串行做一遍，不许跳片。

---

## 一、分片规则（分片之间必须互不重叠）

```
分片 = (国家/地区 × 专业方向簇)  ← 最小执行单元
```

- **按地区切**：每个国家/地区一个分片（比利时 ≠ 荷兰 ≠ 德国）
- **按方向簇切**：GIS/测绘遥感、城市与规划、交通规划、环境与可持续 各自成簇
- 一个分片只查"该地区 + 该方向簇"的项目；**禁止跨片重复检索**（重复＝浪费，漏片＝交付不合格）
- 每片产出**同构**结果（同一 schema），主 Agent 只需合并、去重、排序

分片清单写法（示例，比利时 + 4 方向）：

| 分片 ID | 地区 | 方向簇 | 主要检索入口 | 产出 |
|---|---|---|---|---|
| BE-GIS | 比利时 | GIS/测绘遥感 | 各校理学院地理系 + Study in Flanders | 项目条目 → `data[]` |
| BE-PLAN | 比利时 | 城市与规划 | KU Leuven ICFU、ULB/VUB 建筑与规划 | 同上 |
| BE-TRANS | 比利时 | 交通规划 | UHasselt IMOB 等交通研究所 | 同上 |
| BE-ENV | 比利时 | 环境与可持续 | UGent、ULiège 环境/土地方向 | 同上 |

## 二、每个分片的执行契约（子 Agent 照着做）

```
输入：地区、方向簇、用户档案（GPA/语言/预算/学位年限）
步骤：
1) 打开该地区**官方课程名录**，枚举该方向全部项目（记录翻到的页数/条目数）
2) 逐个进项目页，抄 27 项字段（见 finding-schools.md 第三节）
3) 语言核验：只保留「纯英语」项目；官方写明荷语/法语/德语的 → 进 exclusions，并原文引用官方表述
4) 交叉核验：项目在招？截止日期？学费口径（本地生 vs 非 EEA）
5) 输出两份：projects[]（符合条件，27 字段）+ exclusions[]（学校/项目/理由/来源/核验日期）
6) 不得输出任何未核验的数字；无来源的字段留空并在 note 写「待核验」
```

**子 Agent 输出格式**（JSON，便于主 Agent 直接合并）：

```json
{ "shard": "BE-PLAN", "checkedPages": 14, "candidates": 23,
  "projects": [ { ...27 字段同 data-schema.md... } ],
  "exclusions": [ {"school":"","program":"","reason":"","source":"","checkedDate":""} ] }
```

## 三、主 Agent 的合并与验收

1. **合并去重**：按 `学校+项目` 去重（同名项目在不同分片被查到很常见）
2. **补全链接**：`schoolLinks` / `regionLinks` 缺的补齐（build.js 会强制校验，缺了构建不过）
3. **跑门禁**：`node scripts/build.js` 会校验字段完整性、verifiedDate、policyYear、链接覆盖
4. **验收检索量**（finding-schools.md 7.4）：把各分片的 `checkedPages` 与 `candidates` 加总，对照下限；**多国任务额外按国分组验收**——每个国家独立达标并产出「国家覆盖表」（finding-schools.md 8.0），不许用全部分片的总平均掩盖某个国家的缩水
5. **汇总排除清单**：所有分片的 exclusions 合并 → `assets/exclusions.json` → 页面自动渲染成折叠区/表格
6. **产出**：HTML（按需一个总页或每个地区一页）+ Notion 四表 CSV

## 四、并行度与注意事项

| 情况 | 做法 |
|---|---|
| 1 个地区 × 1 个方向 | 不拆，单 Agent 串行（如本轮比利时） |
| 1 个地区 × 4 个方向 | 拆 4 片，可并行（每片独立入口，无重叠） |
| 3 个地区 × 4 个方向 | 拆 12 片；按"地区"分批并行（同地区多片常共用同一名录页，可共享一次抓取） |
| 用户只给"欧洲" | **先展开成国家清单**（12 大区表），再按国家切片——不许把"欧洲"当成一个国家 |

**禁止**：
- 把同一片派给两个 Agent（重复劳动）
- 分片后不合并（用户拿到 4 份不完整清单）
- 子 Agent 自己补数据（未核验不得写入；发现缺口要回报，由主 Agent 决定再查一轮）
- 用"这片没查到"代替"这片没查"——每片必须给出 `checkedPages` 数字
- 合并时丢弃某个国家的分片、或把某国标成"低优先级"跳过——每个国家分片都必须真实执行并进入国家覆盖表（finding-schools.md 8.0）

## 五、效率提示

- 同一学校的多个项目常在同一目录页 → 每片先抓"名录页"再逐个进项目页，可省一半请求
- 学费/语言/截止三类数据优先核验（它们是判定与筛选的输入），其他字段可后补并标 `verified:false`
- 分片执行前先把 `regionLinks`/`schoolLinks` 的官方入口准备好，子 Agent 直接用，避免各自找入口
