# 准确找学校的检索手册（本技能的核心）

> ⚠️ **本文件是检索线索与核对清单，不是数据结论。**
> 其中的流程、数字、机构名、字段口径都必须由 agent **实时联网核验官网**后才可引用；
> 模型记忆只能决定"去哪里查、查什么"，不得直接充当数据。详见 SKILL.md「铁律零：零记忆交付」。

目标：**找到"用户真能申、信息真准确"的项目**，而不是抄一份看起来像样的院校名单。
准确 = ①项目存在且仍在招 ②要求是最新申请季口径 ③用户条件逐项对得上 ④数据可追溯到官网页面。

---

## 一、检索入口（只用官方源，禁止中介与聚合站）

| 用途 | 入口 | 说明 |
|---|---|---|
| 项目是否存在、要求、学费、截止 | **院校官网**（`xxx.ac.uk` / `xxx.edu.hk` / `xxx.edu.sg` / `xxx.edu.au` / `xxx.de` …） | 唯一可信源；必须进到**项目页**而非院系首页 |
| 官网项目检索 | 各校 `study` / `programmes` / `degree-programs` / `courses` 页面 + 站内搜索 | 用项目关键词搜，不要靠记忆猜 URL |
| 学科排名定位 | QS World University Rankings by Subject（官方站） | 用来判断项目层次，**不用**第三方转载排名 |
| 专业认证（部分专业强相关） | RICS / RTPI（规划）、AACSB/EQUIS（商科）、ABET（工程） | 认证状态直接影响就业与职业资格，别漏 |
| 学制/课程结构 | 项目页 `Programme structure` / `Curriculum` / `Modules` | 这是课程匹配度的唯一依据 |
| 录取实录（辅助） | 官网 `Admissions statistics` / 年度报告（若有） | 官网不披露就**不编**，标"官网未披露" |
| 签证与移民 | **移民局官网**（gov.uk / immd.gov.hk / ica.gov.sg / homeaffairs.gov.au / ind.nl / sem.admin.ch …） | 政策必须查当年版本 |
| 中国学生专属流程 | APS（德国 aps.org.cn）、Universitaly（意大利）、EMGS（马来西亚）等官方门户 | 漏掉会直接卡在签证前 |

**禁止**：留学中介站、聚合排名站、论坛、二手"申请要求汇总"、AI 生成的项目清单。
需要交叉印证时，优先用**学校官方 PDF 手册（Prospectus）**，其次才是权威排名站，且最终以官网为准。

## 二、检索查询式模板

**原则**：先定位学校，再定位项目，最后取字段——不要一步到位搜"XX专业申请要求"（返回的多是中介文）。

```
# 1) 找项目（站内或搜索引擎 site: 限定）
site:<院校域名> <专业关键词> MSc
site:ucl.ac.uk geospatial sciences MSc
site:manchester.ac.uk urban planning masters

# 2) 找要求（进项目页后找这些区块）
entry requirements / admission requirements / 录取要求
English language requirements（注意小分）
fees and funding（学费与奖学金）
how to apply / application deadlines（时间线）

# 3) 找课程结构（课程匹配度的依据）
programme structure / modules / curriculum / study plan

# 4) 找签证（去移民局官网，不去学校页）
<country> student visa requirements China
<country> post study work visa / graduate visa
```

**关键词矩阵**（中英对照，避免搜不到）：
`GIS=地理信息=Geographical Information Science`；`城乡规划=Urban Planning=Urban and Regional Planning`；
`遥感=Remote Sensing`；`数据科学=Data Science`；`城市设计=Urban Design`；`测量=Geomatics=Surveying`；
`空间分析=Spatial Analysis`；`智慧城市=Smart City=Urban Informatics`。
注意英美拼写差异（programme/program、-ise/-ize、MSc/MS、Master/Master's）。

## 三、每个项目必须提取的字段（缺一项＝这条记录不合格）

从项目页与移民局官网抄这 **24 项**，直接映射到 `references/data-schema.md`：

1. 项目全称（原文）+ 中文译名（译名要准确，别自造）
2. 项目官网 URL（**精确到项目页**）
3. 所属院系 / 学系
4. **入学时间 intake（必收，不许写"秋季"了事）**：
   - 具体月份（9 月 / 2 月 / 4 月 / 10 月…），有多轮入学就全记（如「10 月 + 3 月」两季）
   - **入学季 ↔ 申请窗口的对应关系**（例：9/10 月入学 → 前一年 10 月–当年 3 月申请；1/2 月入学 → 前一年 6–10 月申请）
   - 同时抄学制（1 年 / 1.5 年 / 2 年）——**学制 × 生活费 = 总花费**，别只记单年
   - 页面「入学季」筛选器直接依赖 `intake[]`，所以必须写成"9月""2月"这种可枚举值，不要写自由文本
5. 课程结构（核心模块清单，6–8 条，中文写）
6. 学位背景要求（是否限专业、是否接受转专业）
7. 均分门槛（中国院校是否分 List/分档，分档线是多少）
8. 语言要求（总分 + **小分** + 是否可配语言班 / 是否可后补）
9. 是否要 GRE/GMAT、作品集、面试、笔试
10. **先修课程要求**（是否有硬性先修 → 决定"先修风险"标记）
11. 申请材料清单（PS/CV/推荐信数量/成绩单/公证/APS 等）
12. 申请轮次与截止日期（rolling 还是分轮；分轮各轮时间）
13. 录取逻辑（官方口径：按什么排？分轮 or 先到先得；有无面试）
14. 学费（本币 + 币种 + 是否含税、是否按国籍/收入分档）
15. 生活费官方口径（学校或移民局给定的月/年标准）
16. 奖学金（名称 + 金额 + 申请方式 + 是否需要单独申请）
17. **兼职规定（必须查）**：法定时长、是否需许可、假期政策、典型时薪
18. **学生签证（必须查，按中国学生口径）**：签证类型、申请材料（**资金证明形式与金额**——冻结存款/活期流水/保证金，各国口径不同）、体检与保险要求、签证费、官方处理时间、是否需先拿录取函/COE/CAS；**去移民局官网查，不去学校页**；资金证明金额直接决定「预算档」外的现金流压力，漏查=用户被拒签才发 现准备不及
19. **毕业后工签（必须查）**：类型、时长、条件、是否需要雇主
20. **永居 / 入籍路径（必须查）**：年限、语言、收入要求
21. **毕业去向与薪资（必须查）**：典型就业方向、代表雇主、应届薪资区间；**只写有官方就业报告/统计口径支撑的数字，没有就写"官方未披露"**——不许拿招聘网站单点数据当"毕业生薪资"
22. **官方联系方式（必须查）**：招生办邮箱 + 电话（从学校官网 contact/admissions 页实时抄，写进 schoolLinks.contact，禁止凭记忆写）——用户最终要靠它向官方确认申请资格
23. **工作经验要求（必须查）**：是否必须有工作经验、最低年限、是否接受应届、相关实习能否抵扣（MBA/专业硕士常硬性要求，普通理工硕多不要求但别想当然——逐项目核验）；查不到明示要求就写"申请页未列，以招生办答复为准"
24. 数据核验日期 + 来源页说明

**项目名必须逐字核对**：官网叫什么就写什么（含 MSc/MA/MEng 前缀），中文名按官网实质翻译，不确定就保留英文原名并在中文名后加"（原文为准）"。

## 四、核验纪律（"准确"的执行标准）

1. **三源交叉**：项目要求 = 项目页正文 + 招生页（how to apply）+ 官方 prospectus PDF。三者冲突时以**最新**的为准，并在 `sources` 记录分歧。
2. **时效标注**：每条记录写 `verifiedDate`；申请季切换（每年 8–11 月）后旧数据必须重验。无法核验的字段标 `verified:false`，页面会打灰标，**不许冒充已核验**。
3. **区分"最低要求"与"实际录取"**：官网写 2:1（约 80 分）不代表 80 分能录。均分线按"门槛"处理，并在录取判定里把超线 8 分以上才算保底（见 data-schema.md 阈值）。
4. **费用口径写清**：是否含税、是否含保险、是否按国籍分档（德国巴符州/巴伐利亚对非 EU 收费）、是否按学分计费（意大利/西班牙）、两年制是否要乘年数。
5. **语言口径写清**：总分与小分都要，标注"是否可配语言班""是否可后补成绩"。
6. **不确定就写不确定**：宁可标"待核验"，不要填一个看起来合理的数字。**编造数据比缺失数据危害大**。
7. **中国学生特殊项**：德国 APS、意大利 Universitaly 预注册 + 价值声明（CIMEA）、澳洲 GST/GTE、马来西亚 EMGS、比利时的学历认证——这些是硬流程，必须写进 visa 字段与时间线。

## 五、必踩坑清单（每一条都真实发生过）

| # | 坑 | 后果 | 对策 |
|---|---|---|---|
| 1 | 项目更名或已停招，仍在引用旧名 | 用户白准备、投递时发现入口没了 | 进项目页确认招生状态；记录官网当前名称；停招的换成替代项目并注明 |
| 2 | 中英专业名不对应（"城乡规划"不等于 Urban Planning 全部） | 搜不到、错配方向 | 用英文原名检索；确认项目内容（看课程结构）而非只看名字 |
| 3 | 拿"院系录取要求"当"项目要求" | 门槛写错 | 只取项目页 requirements 区块 |
| 4 | 忽略 List/分档（英港新很多学校对中国院校分档） | 均分线判错、误判保底 | 查官网 China list / Band 表，写清"985/211 vs 双非"两条线 |
| 5 | GPA 口径混用（4.0 制、5.0 制、百分制、WES 换算） | 判定全错 | 明确制式，转换时说明换算依据（如 4.0×(百分/100)≈），不同口径不混算 |
| 6 | 语言只看总分不看小分 | 到校被拒或需重考 | 总分 + 小分都写；写作小分是常见卡点 |
| 7 | 学费/生活费按"中介惯例数字" | 预算四档误判 | 用官网学费 + 官方生活标准（移民局/学校给的月标准） |
| 8 | 兼职收入算得太乐观（把法定上限当实际收入） | 用户到了发现补不上缺口 | 上限按"法定时长 × 当地最低/学生工典型时薪 × 保守周数"，并在 note 写明"课程密集时实际无余力" |
| 9 | 忽略学制长度（2 年制总花费是 1 年的两倍） | 预算严重低估 | 算总花费时乘学制年数；澳洲/德国/荷兰多为 1.5–2 年 |
| 9b | 把「入学时间」和「申请截止」混为一谈 | 错过截止、或按错误时点准备 | intake 记录入学月份，timeline 记录申请窗口；两者必须成对核验（9月入学 → 往往前一年 10 月起申请） |
| 9c | 只记"秋季入学"，漏掉春季轮次 | 错过一轮机会（欧陆/澳洲/日本常见两季入学） | 多轮 intake 全部记录；页面按 intake 月份可筛 |
| 10 | 把"毕业后工签"当"能留下工作" | 用户对移民预期错 | 工签时长 ≠ 就业机会；配额/雇主优先/语言要求都要写（瑞士、新加坡典型） |
| 11 | 永居年限直接套用别国经验 | 预期错 | 每国单独查官方年限与条件；注明"是否需放弃原国籍"（德奥西意瑞等需放弃） |
| 12 | 只给 1 倍结果（不给保底校） | 用户没学上 | 候选池必须含 2–3 所保底（超线 ≥8 分且课程对口） |
| 13 | 数据没写核验日期 | 半年后无法判断是否过期 | 每条必带 verifiedDate；页面页脚标核验区间 |
| 14 | 用聚合站/中介站数据 | 二手错误、过时 | 只用官网；排名只用 QS 官方 |

## 六、候选池构建漏斗（从条件到名单）

> **多国任务（目标 ≥2 个国家）在进入本漏斗前，必须先按第八节 8.0 产出「搜索计划」并经用户确认**——搜索计划决定「查哪些国」，本漏斗决定「每国查哪些校」；两步都不许跳。

```
① 锁定变量：目标专业方向（可多选）× 地区（可多选）× 预算上限 × 读研目的
② 生成初始池（15–25 个）：
   - 每个"地区×专业"组合找 3–5 个项目，覆盖 2 个层次（名校 + 稳妥校）
   - 来源：官网项目检索 + QS 学科排名榜（用于确定"名校档"候选）
③ 逐一验真（对每个项目跑第三节 24 项字段）：
   - 项目在招？→ 名称、入口、轮次
   - 条件对得上？→ 均分、语言、先修、材料
   - 费用算得清？→ 学费 + 官方生活费 × 学制
   - 政策查得到？→ 学签、工签、永居、兼职、入籍
④ 计算三张判定：录取四类（保底/主申/冲刺/高风险）+ 先修风险 + 预算四档
⑤ 结构校验（门禁）：
   - 保底 ≥ 2 所，主申 ≥ 3 所，冲刺 ≤ 3 所（防止全冲刺）
   - 预算档①/② 至少 2 所（防止全超预算）
   - 每个地区至少 1 条完整数据（学签+工签+永居+兼职）
   - 全部记录 verifiedDate 齐备，缺失项 ≤ 20%
⑥ 输出：HTML 对比页 + Notion 看板（材料清单 / 时间线 / 政策库）
```

## 七、穷尽性检索规则（任何学校也不要放过）

**原则：不许抽样、不许凭印象挑校。** 先用官方名录把"该地区开设该专业的全部院校"枚举出来，再逐条筛，最后记录排除理由。漏校的代价是用户错过真正合适的项目。

### 7.1 官方课程/学位名录（按地区穷举入口）

| 地区 | 官方穷举入口 | 用途 |
|---|---|---|
| 英国 | Discover Uni（discoveruni.gov.uk，官方课程数据库）；各校 study/courses 页 | 枚举全部受认可课程 |
| 爱尔兰 | QQI 课程与项目名录（qqi.ie） | 认证课程全表 |
| 香港 | 自资专上教育资讯平台（cspe.edu.hk）+ 各校研究生课程页 | 自资/公立研究生课程枚举 |
| 新加坡 | MOE 认可院校名单 + 各校 graduate programmes 页 | 公立大学项目枚举 |
| 澳洲 | CRICOS 注册课程库（cricos.education.gov.au） | 全部对国际生开放课程 |
| 德国 | Hochschulkompass（hochschulkompass.de，官方学位目录） | 全国学位项目检索 |
| 荷兰 | Study in NL（studyinnl.org）+ DUO 课程注册 | 全部英语授课项目 |
| 意大利 | Universitaly（universitaly.it） | 全国学位项目与预注册 |
| 法国 | Campus France + Mon Master（monmaster.gouv.fr） | 硕士项目全表 |
| 西班牙 | RUCT 大学课程注册库（ruct.educacion.gob.es） | 官方学位项目 |
| 奥地利 | studienwahl.at（官方升学平台） | 全国学位项目 |
| 比利时 | 各社区教育部课程库（如 onderwijs.vlaanderen.be）+ 各校 | 学位项目 |
| 瑞士 | swissuniversities（swissuniversities.ch）+ 各校 | 学位项目 |
| 马来西亚 | MQA 认证课程名录（mqa.gov.my） | 认证硕士项目 |
| 日本/韩国 | JASSO / 各校国际生课程页 | 英语授课项目 |
| 全球学科定位 | QS World University Rankings by Subject（官方站，翻全表） | 确定"该专业有哪些学校" 的层次分布 |

> 平台名称与域名以当年为准；**只用官方域**，不用第三方课程聚合站。

### 7.2 检索覆盖三层，缺一层算没做完

1. **名校层**：QS 学科榜前 50 里开设该专业的学校，全表翻完（不许只看前 10）
2. **稳妥层**：排名 50–300 且专业强/性价比高的学校
3. **长尾层**：非名校但项目优质（东欧、北欧、日韩、东南亚、中东），常是低预算用户的真实最优解

**长尾不许跳过**：马来西亚、波兰、匈牙利、葡萄牙、爱沙尼亚等低学费高性价比地区要主动查，不能因为"听起来不够好"就不放进候选池——用户预算紧时它们往往是唯一可行的档①选项。

### 7.3 穷尽判据（什么时候算"搜完了"）

- 官方名录中该专业条目已全部过一遍（记录翻到的页码/条目总数）；
- 连续 2 轮不同检索式（中英文各一轮、site: 限定一轮）**不再出现新院校**；
- 每个"地区 × 专业方向"组合候选数 ≥ 8，总候选池 ≥ 60（用户多地区/多专业时按组合数 × 8 累加）；
- 每个专业方向至少覆盖 3 个地区、每地区至少 2 个不同层次；
- 每个大区至少覆盖 1 个国家/地区（见第八节清单，12 个大区都要过）。

### 7.4 检索量硬门槛（不达标不许交付）

> 这一节的存在理由：agent 天然的偷懒方式是"查到十几个就收工"。以下数字是**交付的必要条件**，任何一项不达标一律视为未完成，必须继续检索。

| 指标 | 下限 | 说明 |
|---|---|---|
| 每个"地区×专业"组合检索的官方页面数 | ≥ 8 页 | 以官网项目页计，不含搜索结果页与中介页 |
| 总候选池（进入排除评估的学校数） | ≥ 60 | 多地区多专业按组合累加，不设上限、越多越好 |
| 完整数据条目（24 字段齐备） | ≥ 30 条 | 用户明确要求"穷尽"时 ≥ 50 条 |
| 每专业方向的数据条目 | ≥ 3 条 | 用户多选 N 个方向 → 总条数 ≥ 3N |
| 每大区的国家/地区覆盖 | ≥ 1 国 | 12 个大区（英伦/港澳/东南亚/东亚/大洋洲/北美/西欧/南欧/北欧/中东欧/中东/非洲拉美）逐区过 |
| 多国任务每国独立达标 | 逐国报告 | 每个保留国一行「国家覆盖表」（检索页数/候选数/入选数/排除数/是否达标）；门槛按每国计，不按合计摊薄（见 8.0 节） |
| 低学费国家条目（年花费 ≤ 15 万人民币） | ≥ 3 条 | 预算 ≤ 25 万时必须满足；预算 ≤ 20 万时 ≥ 5 条 |
| 检索轮次 | 中英文各 ≥ 2 轮 + site: ≥ 1 轮 | 直到饱和判据成立 |
| 排除清单 | 逐条留痕 | 每所被排除的学校都要有具体理由与来源链接 |
| 保底 / 主申 / 冲刺结构 | 保底 ≥ 3、主申 ≥ 3、冲刺 ≤ 4 | 防止全冲刺或全保底的失衡名单 |

**明确禁止（视为交付失败）**：
- 只查 QS 学科榜前 10 就交差
- 只查英语国家，跳过德奥意西波匈捷等低学费地区
- 凭记忆填写要求/学费而不逐页核验
- 把"我没查到"当成"该项目不存在"
- 用中介站、聚合站、论坛内容凑数
- 用户没限定地区时只查用户可能"听说过"的国家
- **多国任务只深查 1–2 个国家、其余国家草草带过或直接从清单上消失**（必须逐国穷举并出国家覆盖表，见 8.0 节）
- 数据条目里出现"待补充""暂无""见官网"这类占位而不去查

**交付前必答自检**（写进最终回复）：
1. 我一共检索了多少个官方页面？候选池多少所？
2. 12 个大区里我过了哪几个？哪些没查到学校、为什么？
3. 我排除了哪些学校、理由是什么？
4. 低学费档（≤15 万/年）我给了几条？用户预算内可行的是哪几所？
5. 有没有"我应该再查一轮但没查"的地方？（有就现在补）

### 7.5 排除也要留痕（结构化，可追溯）

产出**结构化排除清单** `assets/exclusions.json`（页面自动渲染成「排除清单」区），逐条字段：
`school` — `program` — `region` — `reason`（具体理由）— `source`（官方来源链接）— `checkedDate`（核验日期）。

理由必须具体：`语言不符（官方标注荷语/法语授课）` / `硬性先修缺失（如要求法学本科）` / `均分差距 >10 分` / `学费超预算` / `已停招` / `方向不符`。
**禁止**无理由排除，禁止把"没查到"当成"不存在"，禁止用中介站信息作排除依据——排除必须引用官方表述（如"UGent 官方 PDF 写明 two-year programme (Dutch)"）。

### 7.6 与最终名单的关系

```
官方名录穷举（≥60 候选）
  → 排除清单留痕（逐条理由 + 来源，写入 exclusions.json）
  → 完整数据化（≥30 条，含 24 项字段；用户要求穷尽时 ≥50 条）
  → 结构校验：保底 ≥3 / 主申 ≥3 / 冲刺 ≤4 / 预算档①② ≥2 / 每地区政策齐全
  → build.js 自检通过 → HTML 对比页 + Notion 看板 + 定时监控任务
```

> 用户看到的是精选名单，但**穷举与排除过程必须真实发生过**——被问"为什么没有 XX 学校"时要能立刻答出理由；被问"为什么只有这几所"时，要能拿出候选池与排除清单。

## 八、国家/地区穷尽清单（国家也要穷尽，不许只查英澳新）

### 8.0 多国任务搜索计划（先出搜索计划、再逐国穷举——反偷懒硬规则）

**触发**：用户目标地区覆盖 ≥2 个国家——包括"欧洲""北欧""英联邦""欧陆"这类**必须先展开成国家清单**的大区词。

**为什么单列这条**：多国并行时 agent 最典型的偷懒方式是「先深查最容易检索的 1–2 个英语国家，其他国家象征性带过甚至直接不查」。本节就是堵死这条路：**先出书面计划、再逐国穷举、逐国验收**。

**执行顺序（不可跳步）**：

1. **产出搜索计划**（先出搜索计划再穷举，不许一上来就扎进某个国家开始查校）：
   - 第一步：用用户硬约束（预算上限/授课语言/专业方向/学制/读研目的）对 12 大区做粗筛，得到候选大区清单
   - 第二步：大区 → 国家两级筛选，逐国回答下方"每地区必答四问"，得到**保留国清单**——每国写入选理由与预估校数
   - 第三步：被筛掉的国家**逐个写排除理由**（无英语授课/总花费超预算/无该专业硕士/政策风险…）并入排除留痕，不许静默消失
   - 第四步：把搜索计划（保留国 + 排除国 + 各自理由）**展示给用户确认**后再开始穷举；无法当场确认的，在交付物首页展示搜索计划并邀请用户复核
2. **每个保留国独立完整穷举**：逐国执行第七节全部规则与 7.4 全部数量硬门槛（组合 ≥8 页、该国候选数、完整 24 字段数据、三层覆盖、排除留痕）。**数量门槛按「每国」计，不按「全部国家合计」计**——不许把 6 个国家的检索量摊薄成"总量刚好够"，更不许只穷举 1–2 国、其余国家用"参考"两个字带过
3. **国家覆盖表**（交付物必含，写进最终回复与 HTML）：

   | 国家 | 检索官方页数 | 候选池数 | 完整数据条数 | 排除条数 | 达标？ |
   |---|---|---|---|---|---|

   任何一国未达标 → 该国视为**未完成**：要么补查，要么在交付说明里明示"该国未完成 + 差多少"，**不得悄悄从清单上消失**
4. **防缩水自检**（交付前必答）：「如果只保留做得最认真的那个国家，其他每个国家的数据厚度和它一样吗？」不一样就回去补。

## 十、小语种项目检索规则（非英语项目同样要穷尽）

**原则**：用户没限定语言时，**英授与小语种项目都要查**（小语种项目往往学费更低、竞争更小，但就业强绑本地语言）。用户明确要"纯英语"时，才把本语种项目移入排除清单（理由写"非英语授课"，并引用官方原文）。

### 10.1 检索关键词（用官方语言检索，别只用英文）
| 语言 | 检索词 | 授课语言官方字段 |
|---|---|---|
| 德语 | `Studiengang Geodäsie`、`Master Stadtplanung`、`Unterrichtssprache Deutsch` | Unterrichtssprache |
| 法语 | `master géomatique`、`master urbanisme`、`langue d'enseignement` | langue d'enseignement |
| 西班牙语 | `máster geomática`、`máster urbanismo` | idioma de impartición |
| 意大利语 | `laurea magistrale geomatica`、`lingua di erogazione` | lingua di erogazione |
| 荷兰语 | `master geografie`、`onderwijstaal` | onderwijstaal |
| 日语 | `社会基盤学 修士`、`使用言語` | 使用言語 |
| 韩语 | `도시계획 대학원`、`수업 언어` | 수업 언어 |

### 10.2 本地语言证明类型与常见门槛（按当年核验，不要照抄）
- **德语**：DSH-2 / TestDaF 4×4（部分接受 telc C1 Hochschule）；语言班：大学语言中心 / Studienkolleg
- **法语**：DELF B2 / TCF 400+（部分项目要求 C1）；路径：Campus France 语言年、大学语言中心
- **西班牙语**：DELE B2（部分接受校内测试）；语言中心课程普遍
- **意大利语**：CILS/CELI/PLIDA B2；部分英授方向免意语
- **荷兰语**：NT2-II（多数硕士为英授，荷授项目少）；语言班：大学语言中心
- **日语**：JLPT N2（理工科常见）/ N1（文科）；路径：别科（日语别科）、研究生（预科）制度
- **韩语**：TOPIK 4–5 级（理工科 4 级常见）；路径：语学院

### 10.3 小语种项目的取舍（如实告知，不要只讲好处）
- 优势：学费低（德奥/法/日公立）、竞争压力小、当地就业若语言达标反而更容易
- 代价：**语言准备周期长**（德语/日语通常需 1–2 年）、课程与考试全用本地语、就业强绑语言
- **决策规则**：用户无语言基础且时间 ≤1 年 → 优先英授；时间 ≥1.5 年且预算紧 → 小语种路径可行，并把语言班费用与时间计入预算与时间线

### 10.4 排除时的写法
小语种项目被排除时，理由必须引用官方表述（例：`UGent 官方 PDF 写明 "two-year programme (Dutch, 120 credits)"`），并写清"用户要求的语种"——**不要写"语言不符"这种含糊理由**。
